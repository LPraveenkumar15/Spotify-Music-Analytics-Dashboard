# Spotify-Music-Analytics-Dashboard

## 📌 Project Overview

An interactive Spotify Music Analytics Dashboard built using Microsoft Power BI. This dashboard provides insights into song popularity, artist performance, album distribution, and music trends through interactive visualizations and KPIs.

## 🚀 Features

- Interactive dashboard with multiple pages
- Overview of Spotify dataset
- Artist-wise performance analysis
- Song popularity analysis
- Dynamic filters and slicers
- User-friendly navigation
- Modern Spotify-inspired design

## 📊 Dashboard Pages

### 🏠 Home
- Landing page with navigation

### 📈 Overview
- Total Songs
- Total Artists
- Average Popularity
- Album Type Distribution
- Release Year Trend

### 🎤 Artist Analysis
- Top Artists
- Artist-wise Song Count
- Popularity Comparison

### 🎶 Songs Analysis
- Top Songs
- Duration Analysis
- Popularity Ranking
- Album Information

## 🛠️ Tools Used

- Microsoft Power BI
- Power Query
- DAX
- Data Modeling

## 📂 Dataset Columns

- Song Name
- Artist
- Album
- Popularity
- Release Date
- Duration (ms)
- Album Type
- Explicit
- Total Tracks

## 📈 Key Insights

- Identified the most popular artists and songs.
- Analyzed music release trends over the years.
- Compared album types across the dataset.
- Explored song popularity and duration patterns.
- Built interactive reports for quick decision-making.
